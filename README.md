在终端输入start http://127.0.0.1:5001/进入前端
首先进行注册（可以用zhangsan zhangsan123456）
登陆后进入仓库地址选择界面，本次仓库地址：https://github.com/Yuuu2026/Ticketing-System-1-2-task-.git
然后选择立即提取，系统会自动提取在该仓库内最新的修改更新
也可以在下边自己填写，主要因为方便，可以提交一些本次做了什么任务或者老师布置接下来的任务
发布后点击查看采集归档，可以看到系统自动提取github最新的修改，可以通过左上角的时间筛选
可以通过点击链接直接跳转到github本次修改的网页
每个账号登录点击立即提取后，在采集归档内会显示该账号的用户名，避免分工责任混乱
