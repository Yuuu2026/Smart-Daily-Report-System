## 修掉「每分钟弹终端窗口」+ 站点反复掉线

- 现象1：用户反馈每分钟闪一次终端黑框。根因：`DailyReportWebGuard` 用 `-WindowStyle Hidden` 的 PS 命令每分钟触发一次，
  该参数只隐藏窗口自身，控制台仍会先创建再隐藏。`wscript` 启动器被本机安全策略拦截、S4U 后台方式需管理员权限，均不可行。
- 现象2：站点反复掉线，`DailyReportWeb` 的 `LastTaskResult = 3221225786`，即 `0xC000013A = STATUS_CONTROL_C_EXIT`。
  根因：`run_web.cmd` 是控制台程序，控制台被回收时 python 子进程随之收到 Ctrl+C 类信号而静默退出。
- 方案：新增 `scripts/web_supervisor.py`（Python 守护），计划任务改为 `pyw.exe -3.12 scripts\web_supervisor.py`
  （GUI 子系统，**完全无窗口**），登录时启动一次常驻。
  - 每 30s 探测 5000/5001；掉线则用 `subprocess.Popen(..., creationflags=DETACHED_PROCESS|CREATE_NEW_PROCESS_GROUP)`
    重新拉起 `app.py` / `publisher_app.py`，子进程不挂任何控制台，不受父进程退出影响。
  - 回环端口 5099 做单例锁；支持 `--once` 单次修复（与常驻守护共存）。
  - 日志：`.webguard.log`（守护事件）、`.web.out.log`（Flask 输出），均已加入 `.gitignore`。
- 删除：`scripts/ensure_web.ps1`、`scripts/guard_loop.ps1`、`scripts/run_web.cmd`；注销计划任务 `DailyReportWeb`。
- `deploy.yml` 重启步骤改为「结束端口占用进程 + 唤醒守护任务」，由守护在 30s 内自愈，健康检查轮询 120s。
- 验证：手动 kill 两个 Flask 进程 → 17 秒内自动恢复（新 PID 37216 / 19736）；守护进程 `MainWindowHandle = 0`（无窗口）。
- 运维坑：PowerShell 5.1 的 `Start-Process -RedirectStandardOutput` 在本机会因环境变量 `HTTPS_PROXY` 与 `https_proxy`
  大小写不同但字典不区分大小写而抛 `Item has already been added`，无法用它重定向输出；`Start-Process cmd.exe` 也被安全策略禁止。
  这也是最终改用 Python 守护的直接原因。

## 又一处终端弹窗：GitHub Actions runner（17:29 修复）
- 现象：终端反复出现 `1 file(s) copied.` + `√ Connected to GitHub`。
- 根因：runner 由计划任务 `GitHubActionsRunner`（`run.cmd`）启动，run.cmd 自己 `copy run-helper.cmd`（第一行），
  runner 连上后打印第二行；进程被杀后 `web_supervisor` 每 30s 用 `schtasks /Run` 再拉一次 → 每 30s 弹一个窗。
  该任务 `LastTaskResult` 又是 `3221225786 (0xC000013A)`，与控制台回收的老问题同源。
- 处理：删除计划任务 `GitHubActionsRunner`；改为 `web_supervisor.py` 直接 `Popen(bin\Runner.Listener.exe run)`
  + `CREATE_NO_WINDOW`，输出重定向 `.runner.out.log`，失败重试间隔 120s。
- 验证：`√ Connected to GitHub` 只出现在日志里；先遇到 `Conflict`（旧会话未释放），约 100 秒后 `Runner reconnected` /
  `Listening for Jobs`；只有一个 Runner.Listener 进程。
- 结论：**runner 永远不要用 run.cmd / 计划任务启动**，它就是弹窗来源。
- 补充：runner 与 Flask 子进程一样用 `DETACHED_PROCESS`，守护重启时 runner 不会被连带结束（实测 PID 不变）；
  守护每轮先 `tasklist` 查进程，已存在就不重复启动，避免多实例争抢 session。
- `docs/项目讲解脉络.md` 增加「零、大白话版」：收 → 补 → 发 三段讲法 + 小店铺比喻（前台/展示窗/后厨/采购/账本/配送）。
  用户偏好：讲给非技术听众时，先用生活化比喻，再落到文件名。
