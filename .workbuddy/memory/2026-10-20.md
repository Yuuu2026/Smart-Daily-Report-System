  - 无管理员权限 → 装不了 Windows 服务，改用计划任务 `GitHubActionsRunner`（登录自启）拉起 `run.cmd`。

    避免 runner 在 job 结束时清理子进程把网站杀掉。

## 服务守护任务（事故后补）
- 现象：Deploy 重启后健康检查通过，但约 2 分钟后 5000/5001 全部不通，计划任务 `DailyReportWeb` 状态 Ready、
  python 子进程被清掉（怀疑 runner 任务结束清理进程树导致）。Pages 工作流紧接 Deploy 跑完后更明显。
- 处理：新增 `scripts/ensure_web.ps1` + 计划任务 `DailyReportWebGuard`（每 5 分钟，交互登录态、Limited 权限），
  端口未监听时先 Stop 任务、强杀残留监听进程、再 Start，日志写 `.webguard.log`（已 ignore）。
- 验证：手动 kill 两个 python 进程 → 守护 12 秒内自动拉起（新 PID），两站恢复 200。
- 注意：`Stop-ScheduledTask` 不会杀 python 子进程，只停 wrapper，所以守护必须显式按端口强杀。
