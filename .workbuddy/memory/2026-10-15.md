## 启动网站.bat 失效排查

- 现象：用户反馈「启动网站脚本不能用了」。
- 实测：脚本本身正常，能同时拉起 5000（采集端 app.py）和 5001（发布端 publisher_app.py），页面均 HTTP 200。
- 原因：端口 5000/5001 已被先前启动的 python 实例占用（Microsoft Store Python 3.12，WindowsApps 路径），重复启动触发端口冲突，表现为窗口一闪而过/报错。
- 处理：结束占用进程（PID 32136、23788），端口已释放，用户重新双击即可。
- 环境备注：WindowsApps Python 3.12（python3.12.exe）具备 flask + cryptography，缺 keyring；项目读取飞书 Secret 时会回退到本地加密文件，不受影响。

## 启动脚本二次修复（Python 2 问题）

- 用户再报：SyntaxError: Non-ASCII character '\xe5' in start_web.py —— Python 2 报错风格。
- `py -0` 显示机器装有 **Python 2.7**，原脚本选解释器时只检测 `import flask`，不校验版本，导致选中 Python 2 运行项目。
- 改写 `启动网站.bat`：
  1. 新增 :try_python 子过程，先校验 `sys.version_info[0] == 3`，再检测 flask，两项都过才采纳；
  2. 解释器优先级：py -3.12 → anaconda3 → py -3 → python → miniconda3 → LocalAppData Python312（均带 Python 3 校验）；
  3. 开头增加端口占用检测：5000 已监听则直接打开浏览器退出，避免端口冲突闪退；
  4. 输出所选解释器，便于排查。
- 实测：正常启动走 py -3.12，5000/5001 均 HTTP 200；重复运行提示 "The sites are already running. Opening browser..."，不再闪退。
- 注意：bat 内容保持 ASCII，避免中文编码在 cmd 中乱码。
