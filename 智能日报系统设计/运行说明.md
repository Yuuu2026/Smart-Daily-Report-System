# 本地运行

1. 双击项目根目录中的 `启动网站.bat`。
2. 等待脚本提示归档和发布网站都已就绪；浏览器会自动打开归档页。
3. 登录后选择 GitHub 仓库。发布页地址为 `http://127.0.0.1:5001/login`，归档页地址为 `http://127.0.0.1:5000/archive`。
4. 保持启动终端打开。按 `Ctrl+C` 可停止本次启动的网站服务。

首次运行如提示 Flask 未安装，在项目根目录打开终端并运行：

```powershell
python -m pip install -r web/requirements.txt
```

启动器会检查 Flask 和两个页面的响应；若一个服务已在运行，只启动另一个，避免端口重复占用。私有 GitHub 仓库还需要配置有权限的 `DAILY_REPORT_GITHUB_TOKEN` 环境变量。
